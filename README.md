# Predictive Maintenance

This repository contains a predictive maintenance project based on the AI4I 2020 Predictive Maintenance Dataset. The workflow includes data ingestion, preprocessing, feature fusion, and model experimentation.

## Project structure

- data/raw/ - original dataset files
- data/processed/ - cleaned and prepared data
- notebooks/01_ingestion.ipynb - data loading and initial preprocessing
- notebooks/02_fusion.ipynb - feature fusion and analysis steps
- models/ - trained model artifacts and outputs

## Getting started

1. Clone the repository.
2. Install the required Python packages.
3. Open the notebooks in Jupyter to explore the pipeline.

## Dataset

The project uses the AI4I 2020 Predictive Maintenance Dataset for training and evaluation.
